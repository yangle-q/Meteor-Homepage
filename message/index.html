    Welcome to my Homepage!

    Hi there! Welcome to my personal website.🎉

    It is my first time developing a GitHub project. As a practice exercise in Front-end development, I'm very satisfied with this product. I deem this project a great start for me in learning front-end development.

    Indeed, this website is not my first website, or, as you may see on the "My Projects" page, I own several websites for many purposes. But these are all websites that were developed by others, and I've only made a few customisations to them.

    This website was my first time trying to develop a website from scratch, Although it is not a big deal (just a file storage page), it is a remarkable step for me.🤯

    Turning back to this homepage -- my second from-scratch webpage, I used only HTML, CSS and JavaScript to develop it, It took me almost a year to finish it; of course, half the time I was just slacking off (forgive me lol🤣).

    The idea of having a personal homepage came to me when I was 12, and I almost finished the layout of this website at that time. I'm soooo happy to see my dream finally come true; after three years of waiting and one year of development, I think.

    Anyway, I enjoy the progress developing this homepage, and I hope you like it, too. Take a good look around. If you like this page, please give me a star on my GitHub repository or support me on Afdian☕. Of course, if you want to 'appropriate' this page, you can fork it anytime you want. I'll be happy to see that. Thank you for visiting this website, Hope you have a Good time!
